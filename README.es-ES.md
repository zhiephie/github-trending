

# github-trending(Ruby)

## Introducción
Rastreo de los repositorios más populares de GitHub, actualizado diariamente (versión en Ruby)

inspirado en:
 - [github-trending(Go Version)](https://github.com/josephyzhou/github-trending)
 - [github-trending(Python Version)](https://github.com/bonfy/github-trending)


## Ejecutar

Necesitas instalar:

```bash
  $ git clone https://github.com/zhiephie/github-trending.git
  $ cd github-trending
  $ gem install bundler
  $ bundle install
  $ ruby scraper.rb
```

## Avanzado

Un mejor lugar para usar el script es en un VPS

* Debes contar primero con un VPS y luego agregar las claves SSH de tu VPS a GitHub

* Luego puedes ejecutar el código en el VPS

De esta manera, el código se ejecutará sin parar.
